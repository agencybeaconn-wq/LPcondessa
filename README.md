# LP Condessa Beauty — Gel 3 em 1

Página de apresentação do **Gel 3 em 1 da Condessa Beauty** (gel de sobrancelha: fixa, nutre e hidrata).
Marca própria do Condessa Beauty Studio, Ipatinga — MG.

## Como rodar

```bash
node serve.js
# abre em http://localhost:5173
```

Ou abrir `index.html` direto no navegador.

## Estrutura

- `index.html` — página inteira, autocontida (CSS e JS inline, sem build)
- `midia/` — vídeo do hero, fotos do produto, feed do studio, prints de feedback
- `DIRECAO.md` — direção de arte e ficha da oferta
- `INGESTAO.md` — o que foi levantado dos perfis do Instagram
- `PENDENCIAS.md` — o que ainda falta de material da cliente
